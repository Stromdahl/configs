## Description

The keystone slice: **settleup reachable by a stranger at
`https://settleup.stromdahl.io`**, end-to-end through Cloudflare. This builds the
stack every future app on radon reuses, then runs settleup on top of it.

The plumbing this slice establishes:

- **Traefik** serving the static **Cloudflare Origin certificate** via its file
  provider (no ACME), with the fleet's **security-headers** middleware plus a
  **rate-limit** middleware (the apps are unauthenticated).
- The origin cert's private key stored **sops-encrypted for this host** — a new sops
  creation-rule using radon's per-host age recipient (from `issues/022`) — and
  rendered to disk by the deploy script at deploy time.
- A **proxied (orange-cloud)** Cloudflare A record pointing `settleup.stromdahl.io`
  at radon, so the VPS IP is hidden behind Cloudflare with SSL **Full (strict)**.

Then settleup itself: pulling its **public GHCR image**, routed by Traefik at
`settleup.stromdahl.io`, configured with its production base URL and its **SQLite
database on a Docker named volume on the local disk** (so Hetzner snapshots cover
it). **Only Traefik publishes ports** (80/443); no app container publishes to the
host.

Depends on `issues/021` (the zone + origin cert), `issues/022` (the host, the
git-push deploy pipeline, and radon's age recipient), and `issues/023` (the GHCR
image to pull).

## Acceptance criteria

- [ ] settleup loads at `https://settleup.stromdahl.io` with a valid certificate chain, through Cloudflare in Full (strict) mode.
- [ ] An invite link / QR generated by the deployed app uses the `https://settleup.stromdahl.io` base and opens on a phone.
- [ ] radon's real IP is not exposed in public DNS (the record is proxied); only 22/80/443 are reachable and only Traefik publishes ports.
- [ ] settleup's SQLite data survives a container restart (state lives on the persistent volume).
- [ ] A rate-limit middleware and the shared security-headers are applied to the app's router.
- [ ] The stack is brought up by the git-push deploy pipeline with the origin cert sourced from sops.
